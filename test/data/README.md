# Reference data

The tests compare the calculations of `src/` with these files. The first two come from the cited publications, unchanged except for their format. The next two are computed by a reference implementation, with the script that rebuilds them. The next three are test themes and the colors that VS Code itself showed for them. The last two are the themes of 365 Day & Night and the results of its own audit.

| File | Content | Source |
|---|---|---|
| `sharma2005-ciede2000.txt` | 34 pairs of CIELAB colors and their expected ΔE2000. Columns: L1, a1, b1, L2, a2, b2, ΔE2000 | G. Sharma, W. Wu and E. N. Dalal, "The CIEDE2000 color-difference formula: implementation notes, supplementary test data, and mathematical observations", *Color Research & Application* 30(1), 2005, p. 21–30. File `ciede2000testdata.txt` from [G. Sharma's page](https://hajim.rochester.edu/ece/sites/gsharma/ciede2000/) |
| `machado2009-cvd.json` | Simulation matrices of protanomaly, deuteranomaly and tritanomaly, in linear RGB, for severities 0.0 to 1.0. Severity 1.0 is the dichromacy (protanopia, deuteranopia, tritanopia) | G. M. Machado, M. M. Oliveira and L. A. F. Fernandes, "A Physiologically-based Model for Simulation of Color Vision Deficiency", *IEEE Transactions on Visualization and Computer Graphics* 15(6), 2009, p. 1291–1298, DOI [10.1109/TVCG.2009.113](https://doi.org/10.1109/TVCG.2009.113). Table of the [project page](https://www.inf.ufrgs.br/~oliveira/pubs_files/CVD_Simulation/CVD_Simulation.html) |
| `daltonlens-cvd.json` | 216 sRGB colors (6 levels per channel) and their simulation in linear RGB, before clipping, by Brettel 1997 (protanopia, deuteranopia, tritanopia) and Viénot 1999 (protanopia, deuteranopia). Generated by `daltonlens_reference.py`, which gives the command | [DaltonLens-Python](https://github.com/DaltonLens/DaltonLens-Python) 0.1.5, MIT license, simulators with their default parameters. Methods: H. Brettel, F. Viénot and J. D. Mollon, "Computerized simulation of color appearance for dichromats", *JOSA A* 14(10), 1997, p. 2647–2655; F. Viénot, H. Brettel and J. D. Mollon, "Digital video colourmaps for checking the legibility of displays by dichromats", *Color Research & Application* 24(4), 1999, p. 243–252. Choice of models: [DaltonLens comparison](https://daltonlens.org/opensource-cvd-simulation/) |
| `colorlib-reference.json` | 232 colors and 232 pairs: CIELAB, every simulation of the audit, contrast, CIE76, CIEDE2000 in every vision, and transparent colors composed on a background. Generated by `colorlib_reference.py`, which gives the command | `scripts/themes/colorlib.py` of [365 Day & Night](https://github.com/mickaellherminez/365-daynight-vscode-theme-ext) (MIT license), where this audit comes from. The commit is written in the file |
| `oracle-extension/` | An extension of four test themes, one per theme type, written for this package (MIT license). They set few colors, with transparency, an `include`, `"default"` and a color that VS Code shows in red, so that VS Code derives most of the others. The extension contributes two colors of its own | Written for these tests |
| `oracle-keys.txt` | The 251 color ids recorded for these themes: the colors that the checks of the audit of 365 Day & Night read, colors whose defaults use each transform of VS Code, and the two colors of the extension | Chosen for these tests; the keys have the same defaults in VS Code 1.146.0 and in the pinned release, 1.147.0 |
| `vscode-oracle.json` | The colors that VS Code showed for each of these themes and keys, as written in its CSS variables (`#rrggbb`, or `rgba(r, g, b, a)` with an alpha of two decimals), or `null` when VS Code had none | VS Code 1.146.0 on macOS, recorded by `scripts/vscode-oracle.ts`, which gives the command (the version and the commit are written in the file) |
| `365/` | The 48 themes of 365 Day & Night, and a manifest with their `contributes.themes` and `contributes.colors` | [365 Day & Night](https://github.com/mickaellherminez/365-daynight-vscode-theme-ext), MIT license (`365/LICENSE`), copied by `audit_reference.py` (the commit is written in `audit-reference.json`) |
| `audit-reference.json` | For each of these themes, the checks of `audit.py` (label in English, value, minimum, status), the pairs to tell apart with their closest model, achromatopsia, and the variety of `variety.py` for each theme type. Generated by `audit_reference.py`, which gives the command | `scripts/themes/audit.py` and `variety.py` of 365 Day & Night, MIT license |

The data of Sharma et al. are provided by their authors "as is", to check an implementation of CIEDE2000.
